Combining Konva's robust 2D scene graph with the immense parallel processing power of WebGPU inside Web Workers unlocks features that used to require a massive cloud infrastructure.

Since we are pushing heavy tensor operations off the main thread, the Konva canvas will remain buttery smooth at 60fps even while running complex AI tasks.

Here are five high-value features you can build using this exact architecture:

### 1. Magic Eraser (Inpainting) — PARKED (Pass L)

* **The UX:** A user has a great photo but there is a trash can or a photobomber in the background. They select a brush tool, paint a rough highlight over the unwanted object, and it seamlessly vanishes, replaced by a mathematically hallucinated background.
* **The Implementation:**
* Let the user draw over the image using a `Konva.Line` with `globalCompositeOperation="source-over"` to create a visible brush stroke.
* Export the image and the brush stroke layer as two separate pixel arrays.
* Send them to the Web Worker and run a lightweight ONNX inpainting model (like **LaMa** - Large Mask Inpainting) via WebGPU.
* The worker returns the patched image, and you seamlessly update the `image` property of the `Konva.Image` node.



### 2. "Text-Behind-Subject" (Magazine Depth Effect) — SHIPPED (v2.1, Pass J)

* **The UX:** The trendy editorial effect where a large text heading sits *behind* the subject of a photo but *in front* of the photo's background.
* **The Implementation:** You can actually reuse the RMBG-1.4 model from your background removal spec for this.
* When the user clicks "Text Behind Image", send the image to the Web Worker to generate the alpha mask of the subject.
* On the Konva stage, you create a visual "sandwich" in the layer hierarchy:
* `Z-Index 1:` The original, untouched `Konva.Image`.
* `Z-Index 2:` The `Konva.Text` element.
* `Z-Index 3:` A new `Konva.Image` containing *only* the cutout generated by the worker, perfectly snapped to the same X/Y coordinates as the original.


* This creates the perfect illusion of depth with zero complex masking required from the user.



### 3. Smart Crop (Auto-Framing for Canva Frames) — PARKED (Pass N)

* **The UX:** When a user drops a horizontal landscape photo into a vertical Canva Frame (clipping mask), the center of the image is often just empty space, while the person standing on the left gets cut out. Smart Crop automatically shifts the image inside the frame to center the most important subject.
* **The Implementation:**
* Send the dropped image to the Web Worker and run a lightning-fast object detection model (like YOLO-nano) or a face-detection model via MediaPipe.
* The worker returns the X/Y coordinates of the primary subject.
* On the main thread, calculate the offset and automatically adjust the `cropX`, `cropY`, `cropWidth`, and `cropHeight` properties of the `Konva.Image` so the bounding box of the detected subject sits dead-center in the frame.



### 4. AI Image Upscaling (Super Resolution) — PARKED (Pass M)

* **The UX:** Users constantly upload small, pixelated, or heavily compressed images from the web. Offer a "1-Click Enhance" button that makes the image crisp and high-definition.
* **The Implementation:**
* Send the low-res asset to the Web Worker.
* Run a quantized Super Resolution model (like **Real-ESRGAN**) via WebGPU to hallucinate the missing details and output a 2x or 4x larger image.
* Update the `Konva.Image` source with the new high-res asset, but *keep the Konva node's width and height exactly the same*. This packs more pixels into the same canvas footprint, making it look incredibly sharp on Retina displays.



### 5. Depth-Based "Portrait Mode" (True Bokeh) — SHIPPED (v2.2, Pass K)

* **The UX:** The user clicks a flat, standard photo and applies a "Portrait Mode" filter, which artificially blurs the background while keeping the subject perfectly sharp, simulating a high-end DSLR camera.
* **The Implementation:**
* Pass the image to the Web Worker and run a monocular depth estimation model (like **DepthAnything v2**).
* Instead of returning a cutout, the model returns a grayscale depth map (where white is close to the camera, and black is far away).
* Konva allows you to create custom WebGL filters (`Konva.Filter`). You can write a custom shader that reads the depth map and applies a variable Gaussian blur to the original image—pixels that map to "black" on the depth map get heavily blurred, while pixels that map to "white" remain sharp.
